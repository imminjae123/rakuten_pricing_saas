1

.env ファイルを作成してAPIキーを設定する

.env.example というファイルがすでにプロジェクトにあります。
これをコピーして .env という名前で保存し、APIキーを書き込みます。

⚠️ 重要：.env は絶対に Git にコミットしてはいけません。
プロジェクトの .gitignore に .env が登録済みなので、 正しく操作すれば自動的にコミットされません。.env.example は安全にコミットできます。

① ターミナルでコピー（PowerShell）

PS> cd yahoo_pricing_saas
PS> Copy-Item .env.example .env

② .env をエディタで開いて APIキーを入力

yahoo_pricing_saas/.env を VS Code等で開き、以下の行を編集します：

# 変更前（コピー直後の状態）
YAHOO_CLIENT_ID=your_yahoo_client_id_here

# 変更後（あなたのClient IDに書き換える）
YAHOO_CLIENT_ID=dj0zaiZpPXh4eHh4eHh4  ← ここに実際のClient IDを入力
Yahoo! Client IDの確認場所：
Yahoo! JAPAN デベロッパーネットワーク にログインし、 アプリ管理ページから「Client ID」をコピーしてください。

📄 .env の全体像（今回使う最低限の設定）

APP_ENV=development
PORT=8000

# ↓ ここだけ今すぐ入力すればOK
YAHOO_CLIENT_ID=あなたのClient ID

# ↓ 以下はSTEP 2以降で設定するので今は空欄でOK
DATABASE_URL=postgresql+asyncpg://...
REDIS_URL=redis://localhost:6379/0
LINE_CHANNEL_ACCESS_TOKEN=
SECRET_KEY=
2

仮想環境を作成してライブラリをインストールする

Python の「仮想環境」とは、このプロジェクト専用のライブラリ置き場です。
他のプロジェクトと混在しないように、必ず仮想環境の中で作業します。

① 仮想環境を作成して有効化（初回のみ）

# yahoo_pricing_saas ディレクトリの中で実行
PS> python -m venv .venv

# 有効化（Windows PowerShell）
PS> .venv\Scripts\Activate.ps1

# 有効化に成功すると、プロンプトの先頭に (.venv) と表示される
(.venv) PS>  ← このように変わればOK
「実行ポリシー」エラーが出た場合：
PowerShell を管理者として開き、以下を一度だけ実行してください：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

② 必要なライブラリをインストール

(.venv) PS> pip install httpx python-dotenv
ライブラリ役割なぜこれ？
httpx Yahoo! Shopping APIへのHTTPリクエスト送信 後でFastAPIの非同期処理（async）でも同じライブラリを使う。requests より将来性が高い
python-dotenv .env ファイルの読み込み APIキーをコードに直書きせず安全に管理できる

③ インストール確認

(.venv) PS> pip list
# 以下が含まれていればOK
httpx          0.2x.x
python-dotenv  1.x.x

エラーが出た場合のチェックリスト

エラーメッセージ原因解決方法
❌ YAHOO_CLIENT_ID が設定されていません .env ファイルがない、またはIDが your_yahoo_client_id_here のまま .env.example を .env にコピーしてClient IDを正しく入力する
HTTP 400 / 403 Client ID が無効またはAPIアクセス権なし Yahoo! デベロッパーネットワークでClient IDを再確認する
HTTP 429 1秒間に複数回リクエストを送った（レートリミット） 少し待ってから再実行する（本番では1秒1回制限を守る）
ModuleNotFoundError: No module named 'httpx' 仮想環境が有効化されていない、またはインストール未完了 仮想環境を有効化（.venv\Scripts\Activate.ps1）してから pip install httpx python-dotenv
TimeoutException ネットワーク接続の問題 インターネット接続を確認して再実行する
検索結果が 0件 キーワードのスペルミス、または日本語変換の問題 英語キーワード（例: Switch）で試してみる

📖 スクリプトの構造（何がどこで何をしているか）

test_yahoo_api.py の4つのブロック

ブロックやっていること本番実装との関係
① load_dotenv() .env を読み込んで
YAHOO_CLIENT_ID を取得		 本番では pydantic-settings の get_settings() が同じ役割をする
② パラメーター設定 検索キーワード・件数・ソート順を辞書で作成 本番のクローラー（crawl_service.py）でも同じパラメーターを使う
③ httpx.AsyncClient Yahoo! Shopping APIにHTTPリクエストを送信してJSONを受け取る 本番では YahooShoppingClient（app/services/yahoo.py）が同じ処理を担う
④ エラーハンドリング 400・403・429・タイムアウトを個別にキャッチして日本語メッセージを表示 本番のレートリミット制御（Token Bucket）の前段となる概念
