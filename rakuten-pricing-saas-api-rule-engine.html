Rakuten Pricing SaaS — API 仕様書

FastAPI · RESTful · RBAC (OWNER / MANAGER / VIEWER) · JWT Bearer · API prefix: /api/v1

共通規則: 全エンドポイントは Authorization: Bearer <access_token> ヘッダーが必要（/auth/register / /auth/login を除く）。 エラーは {"detail": "...", "code": "..."} 形式で返す。全レスポンスは application/json。

5. evaluate_rule() — Pure Function 設計

Pure Function evaluate_rule(rule_condition, competitor_prices, cost, min_margin_amount, min_margin_rate)
DBアクセスなし・副作用なし・I/Oなし。シミュレーションエンドポイントとWorkerタスクの両方から呼び出す。

評価ステップ (AGENTS.md 準拠)

ステップ処理内容実装箇所
Step 1competitor_filter に従い基準価格を決定
ALL_MAPPED → min(prices) / PRIMARY_ONLY → prices[0]		_select_reference_price()
Step 2ルール戦略から raw_price を計算_compute_raw_price()
Step 3防衛価格フロアを計算 (ルール個別 → 商品レベルの優先順)_compute_effective_floor()
Step 4max(raw_price, defensive_floor) でフロア適用evaluate_rule()
Step 5price_ceiling が設定されていれば上限キャップevaluate_rule()

具体的な計算例

例1: BEAT_LOWEST — 通常ケース

competitor_prices = [4500, 4800, 5000], cost = 3000, min_margin = 500
Step1: reference = min([4500,4800,5000]) = 4500
Step2: raw_price = 4500 + (-10) = 4490   (FIXED adjustment, value=-10)
Step3: floor = 3000 + 500 = 3500
Step4: 4490 >= 3500 → floor_applied=false
Step5: price_ceiling=null → skip
→ recommended_price = 4490

例2: BEAT_LOWEST — 防衛価格フロア発動

competitor_prices = [3200, 3400], cost = 3000, min_margin = 500
Step1: reference = 3200
Step2: raw_price = 3200 + (-10) = 3190
Step3: floor = 3000 + 500 = 3500
Step4: 3190 < 3500 → floor_applied=true, price = 3500
→ recommended_price = 3500  ← 防衛価格で固定

例3: BEAT_LOWEST (PERCENTAGE, -2%) + 上限キャップ

competitor_prices = [10000], cost = 5000, min_margin = 500, price_ceiling = 9800
Step1: reference = 10000
Step2: raw_price = 10000 × (1 - 0.02) = 9800
Step3: floor = 5000 + 500 = 5500
Step4: 9800 >= 5500 → floor_applied=false
Step5: 9800 <= 9800 → ceiling_applied=false  (ちょうど天井)
→ recommended_price = 9800

例4: PERCENTAGE_MARKUP — 原価マークアップ20%

competitor_prices = [],  cost = 3000, min_margin_rate = 0.15
Step1: reference = None  (不要)
Step2: raw_price = 3000 × (1 + 0.20) = 3600
Step3: floor = 3000 × (1 + 0.15) = 3450   (min_margin_rate使用)
Step4: 3600 >= 3450 → floor_applied=false
→ recommended_price = 3600

例5: FIXED_PRICE — 固定価格4,980円 (フロアより高い)

competitor_prices = [any], cost = 3000, min_margin = 500
Step2: raw_price = 4980   (adjustment.value = 4980)
Step3: floor = 3500
Step4: 4980 >= 3500 → floor_applied=false
→ recommended_price = 4980

Margin Override 優先順位

優先度ソース使用条件
1 (最高)rule.condition.constraints.min_margin_amountルール個別オーバーライド (¥額指定)
2rule.condition.constraints.min_margin_rateルール個別オーバーライド (率指定)
3my_product.min_margin_rate商品レベル率指定 (ルールに overrideなし)
4 (最低)my_product.min_margin_amount商品レベル額指定 (フォールバック)

サポートされる condition.type 一覧

type必要フィールド説明
BEAT_LOWESTadjustment.mode + value競合最安値より固定額/率で調整
MATCH_LOWESTなし競合最安値に完全一致
FIXED_PRICEadjustment.value (価格)競合価格に関わらず固定価格
PERCENTAGE_MARKUPadjustment.value (率 e.g. 0.20)cost × (1 + rate) 原価マークアップ
